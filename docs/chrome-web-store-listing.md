# Chrome 应用商店上架材料

适用版本：0.3.6  
更新日期：2026-07-28

本文内容用于复制到 Chrome Web Store 开发者后台。提交前应再次对照实际版本、截图和公开隐私政策 URL。

## 商品名称

求职联系助手

## 单一用途

帮助用户在本人已登录的 BOSS 直聘和智联招聘网页中扫描并人工筛选岗位、联系用户确认过的岗位，并可在用户明确开启后托管 BOSS 会话的后续回复。

## 简短描述

在 BOSS 直聘和智联招聘中扫描、筛选并联系已选岗位，可选开启 BOSS AI 会话托管。

## 详细描述

求职联系助手是一款 Chrome 侧边栏扩展，适合希望减少重复求职操作、同时保留岗位筛选控制权的用户。

主要功能：

- 根据岗位、城市和关键词扫描 BOSS 直聘或智联招聘职位；
- 使用规则或用户自己的 AI API 对岗位进行辅助评分；
- 默认不勾选岗位，只有用户筛选、勾选并确认联系批次后才发起首次联系；
- 为 BOSS 直聘已建立联系的会话提供可选 AI 托管；
- 在安全策略允许时自动回复低风险问题；
- 对薪资、面试、到岗、复杂经历和不确定内容创建待确认任务；
- 可选通过飞书机器人发送待确认通知；
- 本地保存额度、静默时段、去重和运行状态。

用户需要自行准备并登录招聘网站账号，可选择配置自己的 AI API Key。扩展不会保证求职结果。自动化操作可能触发招聘平台限制或账号风险，请从少量岗位开始验证并遵守平台规则。

## 当前支持范围

| 能力 | BOSS 直聘 | 智联招聘 |
| --- | --- | --- |
| 岗位扫描与筛选 | 支持 | 支持 |
| 联系已选岗位 | 支持 | 支持 |
| AI 对话托管 | 支持 | 不支持 |

## 权限理由

### `storage`

在浏览器本地保存平台设置、AI 配置、求职资料、岗位选择、每日额度、托管会话、待确认任务和运行恢复状态。扩展不运行自有同步服务器。

### `tabs`

查找用户已经打开并登录的 BOSS 直聘或智联招聘标签页，打开职位详情或聊天页，并把操作限定在对应招聘网站标签页。

### `scripting`

当目标招聘网站的内容脚本尚未加载或页面发生 SPA 导航时，向经过主机和页面校验的标签页注入随扩展打包的本地脚本。扩展不注入远程代码。

### `sidePanel`

在 Chrome 侧边栏展示配置、岗位筛选、执行日志、AI 托管和待确认界面。

### `offscreen`

只在用户主动启动的有界联系任务期间创建轻量离屏文档，帮助 Manifest V3 Service Worker 保持任务协调；任务终止后关闭。

### `alarms`

按用户选择的 5、10 或 15 分钟间隔唤醒 Service Worker，低频检查已经登记并启用托管的 BOSS 会话；也用于到期回复的调度。

## 主机权限理由

### `*://*.zhipin.com/*`

扫描 BOSS 直聘岗位、打开职位/聊天页、读取已登记会话并按用户设置联系或回复。

### `*://*.zhaopin.com/*`

扫描智联招聘岗位、打开职位页并联系用户确认过的岗位。

### `https://api.deepseek.com/*`

用户选择 DeepSeek 并提供自己的 API Key 时，对岗位或会话消息进行分类和生成建议回复。

### `https://api.openai.com/*`

用户选择 OpenAI 兼容模式并使用 OpenAI 官方地址时，调用用户配置的 AI 服务。

### `https://open.feishu.cn/*`

用户明确开启并配置飞书机器人后，发送测试通知和待确认通知。

### 可选 `https://*/*`

仅当用户选择 OpenAI 兼容服务并填写自定义 HTTPS Base URL 时，通过 `chrome.permissions.request` 请求该 URL 的具体来源权限。未配置自定义服务时不会使用。localhost/127.0.0.1/IPv6 loopback 可选权限用于用户本机兼容服务。

## 数据披露建议

以下内容需要根据 Chrome Web Store 后台当时显示的问题逐项选择，不能机械复制：

- 个人通信：是。启用 BOSS AI 托管时会处理 HR 消息和用户回复；
- 网站内容：是。会读取职位、公司、岗位描述和当前聊天内容；
- 身份验证信息：是。用户提供的 API Key、飞书 Webhook 和签名密钥存于浏览器本地，并用于所选服务；
- 用户活动：是。会处理用户勾选岗位、联系状态、会话状态和本地运行日志；
- 个人可识别信息：可能。简历要点、简历图片和招聘会话可能包含用户主动提供的个人信息；
- 数据出售：否；
- 用于广告：否；
- 用于与单一用途无关的信用、贷款或保险：否；
- 传输到第三方：是。仅在用户启用对应功能时发送到招聘网站、用户选择的 AI 服务商和用户配置的飞书 Webhook。

公开隐私政策：

`https://raw.githubusercontent.com/SERAPH125/boss-contact-assistant/main/docs/privacy-policy.md`

说明：商店后台优先使用 raw URL，便于 Google 爬虫直接拉取纯文本；`blob` 页面也可访问，但偶发被判定不可达。提交前必须在无登录/无 GitHub 会话的浏览器窗口中确认该 URL 返回 HTTP 200。

## 审核测试步骤

### 基础安装

1. 安装扩展并点击工具栏图标打开侧边栏；
2. 确认“配置 → 平台”只显示 BOSS 和智联；
3. 在“配置 → API”填写审核方可使用的测试 AI Key，点击“测试连接”并保存；
4. 在“配置 → 求职设置”填写测试关键词、城市和不含真实个人信息的简历要点。

### BOSS 扫描与联系

1. 在同一浏览器登录可测试的 BOSS 求职账号；
2. 选择 BOSS，保存并扫描；
3. 进入“岗位筛选”，核对列表默认没有勾选；
4. 勾选一个允许测试的岗位，点击“联系已选”；
5. 在确认单中核对目标和数量后确认；
6. 在“执行”页查看结果。

### BOSS AI 托管

1. 打开“配置 → AI 托管”；
2. 开启全局托管，配置检查间隔、额度和 HR 常用问答；
3. 在 BOSS 聊天页打开一个已经建立联系、允许测试的会话；
4. 点击“从当前 Boss 聊天页登记”并开启该会话托管；
5. 点击“立即检查已登记岗位”或等待 alarm；
6. 用测试 HR 账号发送低风险问题，观察扩展按策略自动回复或创建待确认；
7. 用测试 HR 账号发送薪资、面试或复杂经历问题，确认进入“待确认”；
8. 关闭单会话或全局托管，确认后续不再自动处理。

### 智联扫描与联系

1. 登录可测试的智联求职账号并选择智联；
2. 配置城市、经验和学历后扫描；
3. 人工勾选一个允许测试的岗位；
4. 在确认单核对后执行联系；
5. 确认扩展没有展示智联 AI 托管能力。

### 飞书通知

1. 在“AI 托管”中开启飞书通知；
2. 填写审核专用 Webhook 和可选签名密钥；
3. 点击“发送飞书测试通知”；
4. 创建待确认内容，确认通知进入对应飞书群；
5. 在插件中处理最终确认。

审核账号、AI Key、飞书 Webhook 和测试岗位不得写入商店描述、公开仓库或截图，应通过 Chrome Web Store 审核说明中的私密字段提供。

## 自动外发审核风险

当前版本按产品决定保留：用户开启全局和单会话 AI 托管后，满足安全策略的低风险回复可能在不逐条确认的情况下自动发送给已登记 HR。

Chrome Web Store 对代表用户发送消息的能力要求严格，这一行为存在显著拒审风险。提交时必须如实说明，不得把功能描述成“仅生成草稿”。如果审核方不接受，需要由产品负责人决定是否另建商店合规版本；当前发布链路不会静默关闭该功能。

## 提交前检查

- ZIP 由 `npm run package:chrome` 生成；
- ZIP 根目录存在 `manifest.json`；
- 商店描述与版本功能一致；
- 隐私政策 URL 无需登录即可访问；
- 权限理由与 Manifest 一致；
- 数据披露包含 AI、飞书、招聘网站和自动回复；
- 截图无真实凭据或个人通信；
- 审核测试账号和服务凭据可用；
- 已评估自动外发审核风险；
- 没有使用“绝对安全”“不会封号”等无法证明的表述。
