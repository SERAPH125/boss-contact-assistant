# 求职联系助手隐私政策

生效日期：2026-07-28  
适用扩展：求职联系助手

本隐私政策说明“求职联系助手”浏览器扩展会处理哪些数据、为什么处理、数据可能发送到哪里，以及用户如何删除数据。

## 1. 扩展的用途

求职联系助手帮助用户在自己已经登录的 BOSS 直聘和智联招聘网页中扫描岗位、人工筛选岗位、联系用户确认过的岗位，并可在 BOSS 直聘中登记会话、监控 HR 新消息和提供 AI 回复。

扩展不经营招聘服务，不代表招聘平台，也不保证求职结果。

## 2. 扩展处理的数据

根据用户实际使用的功能，扩展可能处理：

- 求职设置：目标岗位、城市、包含词、排除词、招呼语、简历要点和可选简历图片；
- 招聘网站数据：职位名称、公司、薪资、岗位描述、联系人、会话标识、招聘网站消息和发送状态；
- AI 配置：服务商、API Key、自定义 Base URL 和 API 测试状态；
- AI 托管配置：已登记岗位、会话状态、检查游标、每日额度、静默时段、HR 常用问答、待确认任务和发送意图；
- 飞书配置：Webhook 地址、可选签名密钥和通知状态；
- 运行数据：每日联系计数、已处理岗位、任务日志、暂停或错误状态。

## 3. 数据保存位置

API Key、飞书 Webhook、签名密钥、求职配置和运行状态保存在当前浏览器资料的扩展浏览器本地存储（`chrome.storage.local`）中。

这些数据不会由本项目自有服务器进行集中存储或账号同步。浏览器本地存储不是操作系统钥匙链；能够访问当前浏览器资料或设备的人员可能接触这些数据。

## 4. 数据如何使用

扩展只为用户主动使用的核心功能处理数据：

- 根据求职条件扫描和筛选职位；
- 在用户确认联系批次后操作对应招聘网站；
- 用用户提供的简历事实和问答生成回复；
- 监控用户已经登记并启用托管的 BOSS 会话；
- 创建本地待确认任务并按用户配置发送飞书通知；
- 记录本地运行状态，用于限额、去重、恢复和错误处理。

本项目不会出售用户数据，不会将用户数据用于广告，也不会将数据用于与求职联系助手核心功能无关的信用、保险、贷款或人员画像。

## 5. 自动发送

当用户同时开启全局 AI 托管和具体会话托管后，扩展会低频读取已登记的 BOSS 会话。满足扩展安全策略的低风险回复或明确拒绝后的单次礼貌结束语，可能由扩展自动发送，无需用户对每一条消息再次确认。

重要、不确定、高风险、缺少依据或无法可靠确认目标的内容会进入待确认或停止处理。用户可以关闭全局托管、关闭单个会话托管、设置静默时段和每日自动回复额度。

自动化可能触发招聘平台限制、风控或封号。用户应只在本人有权使用的账号中操作，并自行遵守招聘平台规则。

## 6. 发送给第三方的数据

### 6.1 用户选择的 AI 服务商

用户启用 AI 功能时，扩展可能把职位信息、简历依据、HR 常用问答以及与当前任务有关的招聘网站消息上下文发送给用户选择的 AI 服务商，例如 DeepSeek、OpenAI 或用户配置的 OpenAI 兼容服务。

API Key 仅用于请求用户选择的 AI 接口。第三方 AI 服务商会依照其自己的服务条款和隐私政策处理、记录或保留数据。

### 6.2 飞书

用户开启飞书待确认通知时，扩展可能把公司、岗位、HR、需要确认的原因、经过限制的 HR 消息正文和建议回复发送到用户配置的飞书 Webhook。飞书会依照其自己的服务条款和隐私政策处理通知数据。

### 6.3 招聘网站

用户确认联系岗位或开启 AI 托管后，扩展会在 BOSS 直聘或智联招聘网页中读取页面状态，并可能把招呼语、简历或 AI 回复发送给相应招聘网站及其用户。招聘网站会依照其自己的服务条款和隐私政策处理这些数据。

## 7. 权限使用

扩展使用浏览器权限来保存配置、查找当前招聘网站标签页、在目标页面运行内容脚本、展示侧边栏、维持有界任务和安排托管检查。主机访问范围包括 BOSS 直聘、智联招聘、已支持的 AI 服务地址和飞书。

如果用户配置自定义 OpenAI 兼容 Base URL，扩展会在用户操作时申请该具体 HTTPS 来源的可选主机权限。

## 8. 数据保留与删除

本地配置和运行状态会保留到用户修改、清除或卸载扩展为止。用户可以通过以下方式删除数据：

1. 在扩展界面移除已登记岗位、待确认任务或相关设置；
2. 在浏览器扩展管理页清除“求职联系助手”的站点/扩展数据；
3. 卸载扩展，删除该浏览器资料中的扩展本地数据。

清除本地数据不会删除已经发送到招聘网站、AI 服务商或飞书的数据。此类数据的删除需要按照对应第三方服务的功能和政策处理。

## 9. 数据安全与限制

扩展使用 Manifest V3，并把运行代码随扩展包本地发布，不从远程下载和执行扩展代码。扩展会对目标会话、消息方向和发送结果进行校验，但无法保证第三方网页结构、网络、浏览器或招聘平台长期稳定，也无法保证绝对安全。

请不要在简历要点、HR 问答或自定义 API 地址中填写完成任务不需要的敏感个人信息。

## 10. 儿童隐私

本扩展面向具有求职和招聘平台账号使用资格的用户，不以儿童为目标，也不会主动收集儿童数据。

## 11. 政策更新

功能、数据流或第三方服务发生实质变化时，本政策会更新日期和内容。重大变化应在新版本发布说明或扩展界面中提示。

## 12. 联系方式

如有隐私或数据处理问题，请通过项目的 [GitHub Issues](https://github.com/SERAPH125/boss-contact-assistant/issues) 联系维护者。请勿在公开 Issue 中提交 API Key、Webhook、签名密钥、完整简历或真实聊天记录。
