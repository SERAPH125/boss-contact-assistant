# Chrome 应用商店图片素材设计

日期：2026-07-28  
适用版本：0.3.6

## 目标

为“求职联系助手”制作一套可直接上传 Chrome Web Store 的图片素材，准确展示当前版本能力，同时避免暴露真实求职账号、HR、会话、简历、API Key、Webhook 或其他个人数据。

## 交付清单

输出目录固定为 `docs/store-assets/`：

| 文件 | 尺寸 | 内容 |
| --- | --- | --- |
| `01-job-screening.png` | 1280×800 | 岗位筛选：默认不选、AI 评分和人工勾选 |
| `02-contact-confirmation.png` | 1280×800 | 联系确认：已选岗位、数量和确认边界 |
| `03-ai-trusteeship.png` | 1280×800 | AI 托管：检查间隔、静默时段和已登记会话 |
| `04-human-confirmation.png` | 1280×800 | 待确认：高风险问题、建议回复和人工处理 |
| `05-execution-log.png` | 1280×800 | 执行页：成功、跳过、暂停和安全提示 |
| `promo-small-440x280.png` | 440×280 | 小型宣传图块 |
| `promo-marquee-1400x560.png` | 1400×560 | 顶部宣传图块 |

全部文件使用 24 位 PNG，不含 Alpha 透明层。

## 视觉方向

采用用户确认的“混合型”方案：

- 五张功能截图以真实扩展界面为基础；
- 截图中的数据全部替换为合成演示数据；
- 两张宣传图使用品牌化排版，组合扩展图标、产品名、核心价值和简化界面卡片；
- 整体保持当前产品的蓝青色主色、白色背景、浅灰分区和橙色确认操作；
- 不伪造 Chrome、BOSS 或智联的官方背书，不使用招聘平台 Logo 作为主视觉。

### 2. 联系确认

主标题文案：“确认目标后，再开始联系”

画面展示：

- 明确的“返回修改”和“确认联系”按钮；

### 3. AI 托管

主标题文案：“低频检查，持续跟进已登记会话”

画面展示：

- 静默时段；
- 3 个虚构已登记岗位，状态分别为“等待 HR”“延时回复”“等待确认”；

### 4. 待确认

主标题文案：“重要问题，由你最终确认”

画面展示：

- 虚构 HR 问题：“方便告知期望薪资范围吗？”；
- 原因为薪资问题，需要人工确认；
- 一条可编辑的合成建议回复；
- “打开会话”“修改并确认发送”“不回复并移除”；
- 不出现真实工资、真实公司或个人经历。

### 5. 执行记录

主标题文案：“每一步都有记录”

画面展示：

- 成功、跳过、等待和安全暂停四类合成日志；
- 显示联系数量和剩余额度；
- 明确提示目标会话不确定时不会发送；
- 不使用“保证安全”“规避风控”等无法证明的表述。

## 宣传图构图

### 440×280 小型宣传图块

- 左上角：扩展图标与“求职联系助手”；
- 主文案：“筛选岗位，联系已选”；
- 副文案：“可选 AI 托管后续会话”；
- 右侧或底部放置三张简化流程卡：岗位筛选、确认联系、AI 托管；
- 小尺寸优先保证产品名和主文案清晰，不堆叠细节。

### 1400×560 顶部宣传图块

- 左侧：产品名、主标题和两行能力说明；
- 主标题：“把重复求职操作，交给更清晰的流程”；
- 能力标签：“岗位筛选”“仅联系已选”“AI 会话托管”；
- 右侧：一张岗位筛选卡和一张 AI 托管卡的叠放示意；
- 保留充足安全边距，重要文字不贴边；
- 不把自动外发隐藏为“仅生成草稿”，但宣传图不展开复杂政策说明。

## 数据与隐私规则

- 使用虚构公司、岗位、HR 和聊天正文；
- 不读取或截取用户当前 BOSS/智联真实会话；
- 不展示 API Key、飞书 Webhook、签名密钥或浏览器账号；
- 不展示真实头像、真实公司 Logo、联系方式、简历或精确会话 ID；
- 如使用现有扩展状态作为视觉基线，只在隔离的 ego-browser 任务空间中临时替换 DOM 展示文本，不写入扩展存储；
- 输出图中不得包含浏览器书签、其他标签页名称、桌面通知或系统个人信息。

## 制作方式

1. 使用 ego-browser 的独立任务空间打开扩展侧栏页；
2. 通过浏览器内临时展示层构造合成数据，不修改生产配置；
3. 将页面设为目标截图尺寸并直接捕获，避免后期拉伸；
4. 宣传图使用本地 HTML 画布按目标尺寸排版，再通过 ego-browser 直接截图；
5. 每张图保存后检查尺寸、色彩模式、透明通道、文字可读性和隐私内容。

## 验收标准

- 共 7 张 PNG，文件名与尺寸完全符合交付清单；
- 图片没有 Alpha 通道；
- 1280×800 截图在 100% 缩放下文字清楚；
- 440×280 图块缩略显示时仍能识别产品名和主文案；
- 所有内容与当前 v0.3.6 功能一致；
- 自动托管被准确描述为可选功能；
- 无真实个人数据、凭据、平台背书或无法证明的安全承诺；
- 使用图片扫描和人工视觉检查各验证一次。
