# 岗位筛选 UI 命名设计

## 目标

把求职联系助手中用户可见的流程阶段“审核”统一改名为“岗位筛选”，让用户一眼看出该页面用于选择准备联系的岗位。

## 范围

- 底部主导航显示“岗位筛选”。
- 扫描完成提示、返回按钮、恢复建议和运行阶段文案统一使用“岗位筛选”或“待筛选”。
- README 与当前开发文档使用新的产品名称。
- 内部 `review` 页面 ID、状态键和函数名保持不变。
- 历史设计记录不回写，避免篡改既有决策背景。

## 验收

- UI 不再显示孤立的“审核”“返回审核”或“待审核”。
- “配置 → 岗位筛选 → 执行”的用户流程保持不变。
- 文案契约测试、相关 UI 测试和完整测试全部通过。
