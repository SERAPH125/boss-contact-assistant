# 求职联系助手：新用户快速上手

适用版本：0.3.6  
预计用时：10～15 分钟

这份手册帮助你第一次跑通：

`安装扩展 → 平台 → API → 求职设置 →（BOSS 可配置 AI 托管）→ 扫描 → 岗位筛选 → 选择联系方式 → 查看结果`

如果还要让 AI 监控 BOSS 直聘中的 HR 回复，请在主流程跑通后继续完成“可选：开启 BOSS AI 托管”。

## 开始前准备

请准备：

- Chrome 或 Edge；
- 已登录的 BOSS 直聘或智联招聘账号；
- 一个可用的 AI API Key；
- 如果开启 AI 托管：飞书群自定义机器人 Webhook；
- 真实、可公开给 HR 的简历要点。

使用期间请保持浏览器运行和招聘网站登录有效。关闭浏览器后，扩展无法继续监控消息。

> 自动化操作可能触发平台限制或账号风险。第一次使用请只处理少量岗位，并逐项核对日志和发送结果。

## 第 1 步：安装并打开扩展

### Chrome

1. 打开 `chrome://extensions`。
2. 打开“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目根目录。
5. 登录招聘网站。
6. 点击扩展图标，打开“求职联系助手”侧边栏。

### Edge

1. 打开 `edge://extensions`。
2. 打开“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本项目根目录。
5. 登录招聘网站并打开扩展侧边栏。

如果项目代码刚刚更新，请先在扩展管理页点击“重新加载”。

## 第 2 步：选择招聘平台

进入“配置 → 平台”：

- 选择 BOSS：可扫描、联系，并可使用 AI 对话托管；
- 选择智联：可扫描和联系。

同一时间只运行一个平台。BOSS 和智联的求职条件、招呼语、每日计数分别保存。

## 第 3 步：配置并测试 AI

进入“配置 → API”：

1. 选择服务商；
2. 填写 API Key；
3. 如果选择 OpenAI 兼容服务，填写 Base URL；
4. 点击“测试连接”；
5. 看到成功提示；
6. 点击“保存 API 配置”。

修改服务商、API Key 或 Base URL 后，要重新测试连接。

API Key 保存在当前浏览器的扩展本地存储中，不会自动同步到另一个浏览器或浏览器资料。

## 第 4 步：填写求职设置

进入“配置 → 求职设置”。

### 求职意向

填写：

- 目标岗位 / 关键词；
- 城市；
- 可选的包含词；
- 明确不接受的排除词。

示例：

```text
目标岗位：跨境电商运营
城市：杭州
包含词：TikTok, 数据分析
排除词：纯销售, 外包
```

### 简历材料

在“简历要点”中按行填写真实事实：

```text
目前在杭州
有 TikTok 店铺运营经历
熟悉内容优化和数据分析
暂无亚马逊独立运营经验
```

简历图片可选。如果配置，扩展只会在目标会话身份可以确认时尝试发送。

### 招呼语

填写第一次联系 HR 时发送的内容，例如：

```text
您好，我对{company}的{jobName}岗位很感兴趣，方便聊聊吗？
```

支持：

- `{company}`：公司名；
- `{jobName}`：岗位名。

### 扫描与联系节奏

第一次建议：

- 扫描 10～20 个岗位；
- 每日上限保持较低；
- 一次只勾选少量岗位；
- 保留合理的岗位间隔和批次休息。

填写完成后：

- BOSS 推荐点击“保存并下一步：AI 托管 →”；如果暂时不需要托管，可点击“跳过 AI 托管，直接扫描 Boss 岗位”；
- 智联点击“保存并扫描智联岗位”，直接进入扫描。

BOSS 完成 AI 托管页的飞书、回复依据和托管规则后，点击“保存全部配置并扫描 Boss 岗位”。托管配置未通过前置校验时不会开始扫描，界面会提示缺少的配置。

## 第 5 步：扫描和筛选岗位

扫描完成后，打开底部“岗位筛选”。

1. 阅读岗位名、公司、薪资、匹配分和理由；
2. 点击职位名可打开站点详情；
3. 点击职位卡其他区域可勾选；
4. 可使用“全选高分”，但仍要人工复核；
5. 只保留你确实愿意联系的岗位；
6. 选择一个批量操作：
   - “联系已选”：只发起联系，不自动开启会话托管；
   - “联系已选并开启 AI 托管”：仅 BOSS 提供，联系成功并可靠登记后立即开启该会话托管。

扫描不会自动联系。未勾选的岗位不会进入联系流程。

## 第 6 步：确认并联系

两个批量操作都会先打开“确认本次联系计划”，不会因为点击入口就立即发送。确认单会明确显示“仅联系”或“联系成功后开启 AI 托管”。

请核对：

- 平台；
- 岗位数量和清单；
- 今日剩余额度；
- 预计等待时间；
- 简历图片状态。

选择：

- “返回岗位筛选”：取消，不会联系；
- “确认联系”或“确认联系并开启 AI 托管”：按确认单中冻结的方式处理本批岗位。

确认单有效期为两分钟，而且只能使用一次。

## 第 7 步：查看执行结果

进入底部“执行”：

- 查看当前阶段和进度；
- 阅读每个岗位的日志；
- 需要时点击“暂停”或“停止”；
- 出现安全停机卡片时，按卡片提示人工处理。

如果遇到验证码、登录失效、次数上限、目标不确定或发送结果未知，不要连续重试。先回到招聘网站核对实际状态。

BOSS 联系成功后，扩展会尝试把会话加入“配置 → AI 托管 → 已登记岗位”。选择“联系已选并开启 AI 托管”时，可靠登记的新会话会直接进入“等待 HR”；选择“联系已选”时只登记，不自动开启。

登记成功应同时看到：

1. “已登记岗位（N）”数量增加；
2. 对应公司、岗位和 HR 卡片出现。

## 可选：开启 BOSS AI 托管

AI 托管只支持 BOSS 直聘。

### 1. 准备回复依据

至少完成一项：

- 在“求职设置”填写简历要点；
- 在“AI 托管 → HR 常用问答”勾选问题并填写答案。

答案必须真实、简短、可以直接发给 HR。

### 2. 配置飞书

在“配置 → AI 托管”：

1. 勾选“启用飞书待确认通知”；
2. 填写飞书 Webhook；
3. 如有签名校验，填写签名密钥；
4. 点击“发送飞书测试通知”；
5. 确认飞书收到测试消息。

飞书只负责通知，最终确认仍在扩展“待确认”页完成。

### 3. 设置托管参数

建议第一次使用：

- 检查间隔：10 分钟；
- 每日自动回复上限：10 或更低；
- 按需开启静默时段；
- 检查 HR 常用问答。

只保存配置时点击“保存托管设置”。如果正按首次配置引导准备扫描，点击“保存全部配置并扫描 Boss 岗位”；它会先保存托管设置，成功后再扫描。输入内容不是边输入边自动保存。

### 4. 开启岗位托管

在“已登记岗位”中：

- 勾选单个岗位的“托管此岗位”；或
- 点击“一键托管全部可用岗位”。

已结束－未匹配、待确认、暂停、延迟中或正在核验发送的会话不会被批量重新开启。

### 5. 手动验证一次

点击“立即检查已登记岗位”，查看：

- 检查了几个会话；
- 是否有新消息；
- 是否产生待确认；
- 是否产生自动回复；
- 是否显示具体失败原因。

普通安全回复检测后还会等待 30～300 秒；静默时段会等到静默结束。

### 6. 了解自动处理边界

可能自动回复：

- 是否仍在看机会；
- 是否对岗位感兴趣；
- 礼貌回应；
- 能从简历或问答直接取得答案的低风险事实问题。

需要你确认：

- 薪资；
- 面试；
- 到岗时间；
- 离职原因；
- 联系方式；
- 经历或项目补充；
- 测评、Offer、承诺、附件；
- AI 不确定或没有事实依据的问题。

明确拒绝被 AI 严格识别后，扩展只会发送一次简短礼貌结束语，并把会话标记为“已结束－未匹配”。

## 遇到问题先检查

### 扫描没有结果

- 招聘网站是否已登录；
- 关键词和城市是否有效；
- 页面是否出现验证码；
- 是否选择了当前已支持的平台；
- 是否刚更新代码但没有重载扩展。

### “联系已选”不可点击

确认至少勾选了一个岗位。重新扫描、切换平台或“清空选择”都会取消原勾选。

### “立即检查”显示检查 0 个

- 全局 AI 托管是否开启并保存；
- 单个岗位是否已经托管；
- 是否有已登记岗位卡片；
- 岗位是否处于待确认、暂停、已结束或核验发送状态；
- API 与飞书测试是否仍有效。

### HR 发消息后没有立刻回复

先检查：

1. 是否已经到下一次 5/10/15 分钟轮询；
2. 最近检查时间是否更新；
3. 是否正在等待 30～300 秒；
4. 是否处于静默时段；
5. 是否进入“待确认”；
6. 是否达到每日上限；
7. 是否缺少可引用的事实依据。

### 飞书配置重新打开后看不到原值

如果输入框显示“已保存；重新输入可替换”，说明配置仍在本地。界面不会重新展示敏感原文。

修改配置后要重新测试，并点击“保存托管设置”。

### 发送结果未知

打开对应 BOSS 会话人工核对。不要再次发送同一内容。核对后在“待确认”中点击“已核对，清除此项”。

## 下一步

主流程已经跑通后，建议按以下顺序扩大使用范围：

1. 先用少量岗位验证扫描和联系；
2. 完善简历要点与 HR 常用问答；
3. 验证飞书通知；
4. 只托管少量 BOSS 会话；
5. 观察一次真实 HR 新消息是否被识别；
6. 确认没有重复回复后再增加托管数量。

完整配置、状态说明和故障排查见 [求职联系助手用户操作手册](user-manual.md)。
